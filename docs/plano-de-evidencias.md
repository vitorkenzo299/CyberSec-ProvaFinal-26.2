# Execução das evidências

As provas reais estão organizadas em [evidencias/INDICE.md](../evidencias/INDICE.md), separadas das capturas locais de preparação. Os JSONs possuem datas de coleta e os testes preservam os resultados. As capturas mostram interfaces reais AWS e Wazuh. Os registros HTML e suas imagens identificam explicitamente que foram gerados a partir de resultados técnicos, sem simular uma interface AWS.

O manifesto SHA-256 deve ser refeito quando uma evidência mudar. O pacote `entrega/Evidencias_Completas.zip` inclui o índice, o manifesto e os arquivos de evidência, sem chave, senha, perfil VPN, estado ou credencial temporária.

Foram preservadas provas de inventário, IAM, rede, VPN, Wazuh, FIM, falhas SSH controladas, WAF, varredura ZAP, restauração e comparação do ambiente anterior. R03 continua pendente de triagem e está documentado com seu inventário real.
